## MODIFIED Requirements

### Requirement: TUI 委派摘要与导航
TUI SHALL 在主 transcript 中显示每轮独立的简短委派卡片，并在有运行任务时显示有界活动摘要；提供鼠标与键盘入口打开子 agent 列表，选择条目进入详情。列表 SHALL 按稳定子 agent 身份去重，包含角色、当前或最近任务摘要及 Idle/Queued/Running 状态；完成/失败/停止与耗时 SHALL 属于各轮，旧轮卡片可定位对应轮次。详情 Esc SHALL 返回上一层，停止 SHALL 使用独立明确操作，绑定当前活动轮，不删除身份或上下文。

#### Scenario: 浏览与停止
- **WHEN** 用户通过点击或键盘选择运行中的子任务，进入详情后按 Esc
- **THEN** 返回列表或主视图而不停止任务；选择停止才取消该任务，兄弟任务不受影响

#### Scenario: 同一子 agent 两轮
- **WHEN** 同一子 agent 第一轮完成后开始第二轮
- **THEN** 列表保留一个条目并显示当前活动状态，主 transcript 保留两张独立任务卡，旧卡状态不被改为第二轮状态

### Requirement: TUI 子 agent 完整可见流程
详情面板 SHALL 展示与主 agent 同类的完整可见调用流程：各轮任务输入与简短分隔、助手文字、已保存的模型思考内容、工具参数、流式输出和最终结果、错误、图片入口及最终报告。SHALL 支持滚动、展开与历史恢复，沿用现有输出截断和终端图片能力，不以最后一条状态替代完整记录。同一子 agent 的各轮 SHALL 沿一条连续历史呈现；详情显示累计用量，各轮摘要可查看本轮增量。

#### Scenario: 多轮工具历史
- **WHEN** 子 agent 搜索、读取、修改并执行验证，随后结束或失败
- **THEN** 每轮可见消息与工具记录均可回看，折叠条目可展开，失败和截断仍可辨识

#### Scenario: 可见思考内容
- **WHEN** 模型返回可展示的思考内容，或未提供思考内容
- **THEN** 前者沿用主会话的折叠展示，后者不伪造思考正文

#### Scenario: 旧轮定位与接续输出
- **WHEN** 用户从第一轮卡片打开详情，随后第二轮产生新输出
- **THEN** 加载并定位第一轮内容，保留回看位置与展开状态；用户主动回到底部后可看到第二轮，主草稿与附件不变

#### Scenario: 用量显示
- **WHEN** 同一子 agent 有两轮已结算及一轮运行中
- **THEN** 累计统计该子会话，各轮摘要分别显示固定值或已记录增量，未知旧值标注未记录，英文提示与当前主题风格一致
