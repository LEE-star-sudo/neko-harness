# Proposal

## Why

TUI `/login` 面板的当前交互有多个可用性缺陷，用户反馈"很难用"：粘贴密钥后按方向键（移动光标的本能操作）会切换 provider 并静默清空已输入内容；粘贴内容完全遮罩、无法确认完整性；从网页复制的密钥常带换行/空格被服务端拒绝，但错误原因被吞掉只显示笼统失败；保存成功后面板不自动关闭；Ctrl+R 无确认即删除已保存密钥。

## What Changes

- **方向键恢复光标语义**：←/→ 在输入非空时执行正常光标移动，仅在输入为空时切换 provider（Tab 始终切换）；切换 provider 前若输入非空，保留内容而非静默清空。
- **粘贴可见性与清洗**：遮罩改为显示"已输入字符数 + 头尾少量明文"的可确认形式；保存前自动去除首尾空白，含内部控制字符时给出具体原因（如"key contains a newline"）。
- **错误透传**：保存/移除失败时显示服务端返回的具体错误消息（不含密钥本身），不再统一为笼统重试提示。
- **保存成功自动关闭**：保存成功后短暂显示确认信息并自动关闭面板、恢复聊天焦点；移除成功后同样处理。
- **移除需确认**：Ctrl+R 移除已保存密钥前要求面板内联确认（再次按键或独立确认步骤），防止误删。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `terminal-ui`: 修改"登录配置"需求——方向键语义、粘贴确认与清洗、错误透传、成功后自动关闭、移除确认。

## Impact

- `packages/tui/src/components/login.ts`：面板交互逻辑与渲染。
- `packages/tui/test/`：登录面板交互测试（方向键、粘贴清洗、确认流程）。
- 不涉及 core/gateway 协议变更；服务端凭据校验保持不变。
