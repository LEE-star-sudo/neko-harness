# Spec Delta

## ADDED Requirements

### Requirement: 移动会话列表排序与时间语义

移动 API 的会话列表 SHALL 按最近消息时间倒序排序，无消息的会话使用创建时间，时间相同按会话 ID 倒序，与电脑 Web 的会话排序一致。每个会话摘要 SHALL 提供最近消息时间，打开会话、重复请求、流式片段、标题生成和配置修改 MUST NOT 改变排序。该字段为新增字段，MUST NOT 提高 API 版本，缺少该字段的旧网关由客户端回退到最近使用时间。

#### Scenario: 打开不改变顺序
- **WHEN** 手机打开或 attach 某个会话但未提交消息，随后重新列出同工作区会话
- **THEN** 该会话的位置与相对顺序不变，摘要中的最近消息时间不变

#### Scenario: 发送后置顶
- **WHEN** 手机或电脑向某会话提交消息并被受理
- **THEN** 该会话的最近消息时间更新，重新列出时位于同工作区首位，并收到会话列表变化通知

#### Scenario: 无消息会话与同时间
- **WHEN** 工作区内存在从未发送消息的新会话，或多个会话时间相同
- **THEN** 新会话按创建时间参与排序，时间相同按会话 ID 倒序，分页游标下无重复、无遗漏

#### Scenario: 版本兼容
- **WHEN** 旧 App 连接新网关，或新 App 连接缺少该字段的旧网关
- **THEN** 旧 App 忽略新增字段并按服务端顺序展示；新 App 回退使用最近使用时间且不报错
