## ADDED Requirements

### Requirement: Web 子 agent 命令审批
Web SHALL 在主会话委派卡和子任务入口显示待审批提示与数量，在输入框附近独立展示完整命令、工作目录、显式超时、允许本次和拒绝操作；窄屏子视图将同一审批区放在底部。决定后移除审批卡，仅在对应命令旁保留结果。SHALL 延续当前工具卡、主题与响应式风格，支持键盘和辅助技术。请求到来不得抢焦点或反复打开用户关闭的侧栏，关闭详情不决定审批。列表可简写命令，审批详情 MUST 可完整查看而不能静默截断。

#### Scenario: 侧栏关闭时到来
- **WHEN** 子 agent 请求审批而用户已关闭侧栏
- **THEN** 主输入区直接显示待审批操作，无需打开子任务即可决定，草稿、附件及主视图滚动状态保留

#### Scenario: 移动端与长命令
- **WHEN** 用户在 375、768、1440、1920 像素宽度查看多行命令
- **THEN** 详情可完整滚动阅读、操作可达且无页面横向溢出，关闭恢复有效焦点，不隐式授权

#### Scenario: 竞争与重连
- **WHEN** 用户提交决定时另一端已处理，或浏览器断线后重连
- **THEN** 展示服务端最终状态且不重复执行，已结算请求不再显示可生效的审批按钮
