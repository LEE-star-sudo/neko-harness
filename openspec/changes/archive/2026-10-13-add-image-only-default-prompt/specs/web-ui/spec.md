# Spec Delta

## ADDED Requirements

### Requirement: Web 默认图片提示查看

Web SHALL 根据服务端投影的默认图片提示元数据，在图片用户消息中显示「默认图片提示」来源标记与折叠查看入口。默认 SHALL 收起正文，保留图片缩略图与预览，不将自动提示作为用户手写文字显示；展开 SHALL 展示该消息保存的完整提示，支持再次收起。入口 SHALL 支持键盘和触屏，具有可访问名称及展开状态，遵循现有主题与响应式布局。

#### Scenario: 展开与收起
- **WHEN** 用户浏览带有默认提示元数据的图片消息并操作查看入口
- **THEN** 默认收起的提示可展开显示完整正文，再次操作收起；图片预览、输入草稿和当前会话保持不变

#### Scenario: 窄屏与键盘
- **WHEN** 用户在 375px 或 1440px 宽度通过键盘或触屏查看较长默认提示
- **THEN** 控件有可辨识名称及展开状态，正文可完整查看且页面不横向溢出，收起后焦点保持在有效入口

#### Scenario: 重连与无标记消息
- **WHEN** 浏览器重连、刷新、切换或打开分叉会话，或显示手写的相同提示正文
- **THEN** 带标记的消息按持久正文恢复查看能力，无标记消息继续按普通用户文字显示，不从字符串内容推断来源
