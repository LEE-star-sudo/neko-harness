# Spec Delta

## ADDED Requirements

### Requirement: TUI 默认图片提示查看

TUI SHALL 根据服务端投影的默认图片提示元数据显示来源标记与查看入口，默认收起提示正文并保留图片预览或文字回退，不将自动提示渲染为用户手写内容。查看 SHALL 展示该消息实际保存的完整默认提示，支持收起；操作标记和说明 SHALL 使用英语，正文保留原文，不从普通文字反向识别默认提示。

#### Scenario: 纯图片消息
- **WHEN** TUI 显示带有默认提示元数据的图片用户消息
- **THEN** 显示图片及 Default image prompt 来源标记，默认不铺开提示正文，用户可点击标记查看完整正文并再次点击收起，不提供额外查看命令

#### Scenario: 小窗口与输入保留
- **WHEN** 用户在 80x24 或 60x16 终端查看较长默认提示，再点击收起内容
- **THEN** 正文可换行或滚动查看，输入、草稿及状态栏保持可用；收起后继续原编辑流程，不发送消息或改变会话

#### Scenario: 恢复与普通文字
- **WHEN** TUI 重启、切换或打开分叉会话，或用户手写了相同的默认提示正文
- **THEN** 有来源标记的消息可查看原持久正文，无标记消息保持原用户文字展示，不因正文相同而隐藏或标记
