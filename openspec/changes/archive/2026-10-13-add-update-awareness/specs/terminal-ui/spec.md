# Spec Delta

## ADDED Requirements

### Requirement: TUI 升级感知与版本查看

TUI SHALL 提供简洁英语升级提示及 `/version` 查看入口，区分可安装更新、需重启 TUI 和需重启 gateway。提示 SHALL 给出实际可执行的下一步，同一状态不重复打扰。界面 MUST NOT 执行安装或自动重启，不将更新提示写入对话或发送给模型；输入、任务与常驻状态栏保持可用。

#### Scenario: 新版本可用
- **WHEN** 后台确认稳定渠道有高于已安装版本的新版本
- **THEN** 显示简短版本提示和 `neko update`，用户在另一个终端或退出界面后自行执行，不将命令作为聊天输入代为运行

#### Scenario: 网关仍旧
- **WHEN** 安装已升级，当前连接的 gateway 仍旧
- **THEN** 提示重新启动本地 neko，并经版本查看入口说明需关闭网关拥有者；复用方不暗示仅重启自己即可更新网关

#### Scenario: TUI 仍旧
- **WHEN** gateway 或已安装版本更新，TUI 仍运行旧构建且协议兼容
- **THEN** 提示退出后运行 `neko tui`，继续保留当前编辑与任务，不因单纯版本差异中断使用

#### Scenario: 查看与检查失败
- **WHEN** 用户输入 `/version` 并查看版本或主动检查更新
- **THEN** 可查看 TUI、gateway、安装与渠道版本，支持退出查看返回原编辑流程；检查失败显示简短重试说明，不宣称已最新

#### Scenario: 窄窗口与提示去重
- **WHEN** 界面在 80x24 或 60x16 下收到重复状态广播，或用户切换会话
- **THEN** 提示不挤出输入和状态栏，不为每个会话重复弹出；版本状态改变后更新提示并移除已解决提醒
