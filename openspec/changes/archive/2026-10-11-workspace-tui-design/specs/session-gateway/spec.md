# Spec Delta

## MODIFIED Requirements

### Requirement: 会话目录
系统 SHALL 维护会话目录（创建、列出、删除会话），目录变化 MUST 实时推送给已连接的前端。每个条目 SHALL 包含持久化的工作区与最近使用信息，以支持前端筛选和恢复。目录保持全局可见，工作区筛选不构成权限隔离。

#### Scenario: 新会话广播
- **WHEN** 任一前端创建会话
- **THEN** 所有已连接前端在目录更新中收到该会话及其工作区

#### Scenario: 最近使用更新
- **WHEN** 会话被成功激活或接受用户输入
- **THEN** 最近使用信息被持久更新并推送，网关重启后仍可据此排序；仅后台输出不改变最近使用顺序

## ADDED Requirements

### Requirement: 多工作区目录一致性
网关 SHALL 在同一存储中托管多个工作区会话。会话投影的工作目录 MUST 来自该会话保存的工作区，不能使用网关进程目录覆盖。新建会话省略目录时 SHALL 使用网关启动时确定的默认工作区。

#### Scenario: 复用另一目录的网关
- **WHEN** 从工作区 B 启动的 TUI 连接启动于 A 的网关并指定 B 创建会话
- **THEN** 新会话的工具默认目录、目录条目与聊天投影均为 B，A 中会话保持不变

#### Scenario: Web 同时连接
- **WHEN** Web 与 TUI attach 同一会话
- **THEN** 两者收到相同工作区与会话状态，Web 仍可浏览全局会话目录
