# Spec Delta

## ADDED Requirements

### Requirement: 工作区文件候选

系统 SHALL 为 @ 引用提供当前工作区的文件与目录候选，支持空查询、名称模糊搜索和相对目录定位。候选 MUST 使用工作区相对路径，不自动提升到 Git 根；默认遵守文件发现工具的忽略规则，包含未被忽略的隐藏项，始终排除 .git。返回候选的真实目标 MUST 位于当前工作区内；该限制仅约束候选功能，不改变工具访问权限。

#### Scenario: 定位与搜索

- **WHEN** 用户在工作区 B 输入 @、@runtime 或 @packages/core/
- **THEN** 分别展示 B 的候选、名称匹配结果或指定目录内候选，目录可辨识，同名文件可通过父路径区分

#### Scenario: 忽略与越界

- **WHEN** 工作区包含被忽略的目录、隐藏项、.git、指向外部的符号链接，或用户输入越出根目录的路径
- **THEN** 被忽略项、.git 和真实目标在工作区外的条目不成为候选；合法隐藏项可见，越界查询明确拒绝

#### Scenario: 大目录与失效目录

- **WHEN** 候选超过返回限制、查询超时或工作区已删除
- **THEN** 查询有界结束，过多候选引导缩小范围，超时和目录失效可辨识且可重试，不静默切到其他目录

### Requirement: 路径引用与附件语义

普通文件及目录选择 SHALL 插入可编辑的 @ 相对路径，带空格的路径 SHALL 正确引用。搜索及选择 MUST NOT 加载正文、递归展开目录或自动发送消息；引用作为消息文字由模型按需使用现有工具读取。图片 SHALL 沿用图片附件能力和模型校验，失败时保留草稿并明确反馈。

#### Scenario: 文件和目录引用

- **WHEN** 用户选择带空格的文件或目录并发送问题
- **THEN** 引用路径准确保留，目录可作为引用发送，消息不包含自动附加的文件全文或目录树

#### Scenario: 图片与失效文件

- **WHEN** 用户选择图片，或选择后文件被删除
- **THEN** 图片处理遵循既有附件限制且不自动发送；普通路径引用仍为文字，实际读取失败由工具反馈，不伪称已附加内容
