# Spec Delta

## ADDED Requirements

### Requirement: Web 右侧工作区栏
Web SHALL 在会话页提供右侧「工作区」栏，含「文件」与「改动」两个标签页，由顶栏入口开合；当前标签与展开的目录、已打开的文件在同一会话内切换栏开合时保留，切换会话时重置。栏的开合与浏览 MUST NOT 改变输入框草稿、附件、聊天滚动位置和输入历史浏览状态。栏默认关闭，不因 agent 修改文件而自动打开。

#### Scenario: 开合保留状态
- **WHEN** 用户打开工作区栏、展开两层目录并查看一个文件后关闭再重新打开
- **THEN** 目录展开状态与所查看的文件保持，输入框草稿与附件未被改动

#### Scenario: 不自动打开
- **WHEN** agent 在栏关闭时修改了文件
- **THEN** 栏保持关闭，仅顶栏入口上的改动数更新

### Requirement: 右侧位置共用
右侧栏 SHALL 与子 agent 面板、后台任务面板共用同一右侧位置，同一时刻只显示其中一个；用户主动打开某一面板时其余面板收起。工作区栏已打开时，子 agent 首次委派 MUST NOT 自动抢占该位置，仅通过消息流中的入口提示；用户关闭其他面板后的恢复规则保持不变。

#### Scenario: 互斥切换
- **WHEN** 工作区栏已打开，用户从顶栏打开后台任务面板
- **THEN** 工作区栏收起，任务面板显示；再次打开工作区栏时恢复此前的标签与浏览位置

#### Scenario: 委派不抢占
- **WHEN** 工作区栏已打开时主 agent 首次委派子任务
- **THEN** 栏保持不变，消息流中的委派卡片与子 agent 入口可用，用户点击后才切换到子 agent 面板

### Requirement: 工作区栏的响应式与可访问性
工作区栏在桌面端 SHALL 以可调整宽度的右侧栏呈现，宽度有最小与最大限制；窄屏（≤1023px）SHALL 以可关闭的抽屉或全屏面板呈现。文件树 SHALL 支持键盘导航（方向键移动、左右展开/收起、Enter 打开），标签页与按钮具有可访问名称，焦点在关闭后回到顶栏入口。在 375、768、1440、1920 像素宽度下 MUST 无横向溢出：长路径折行或省略并可通过标题查看完整路径，代码区在自身容器内横向滚动。

#### Scenario: 键盘操作
- **WHEN** 用户仅用键盘在文件树中移动、展开目录并按 Enter 打开文件
- **THEN** 焦点状态可见，查看器显示所选文件，按 Esc 关闭抽屉后焦点回到顶栏入口

#### Scenario: 各宽度布局
- **WHEN** 用户在 375 与 1440 像素宽度打开栏并查看含长路径、长行代码的文件
- **THEN** 页面无横向溢出，长路径可辨识，代码在查看器内滚动

### Requirement: 工作区栏的旧网关与错误降级
Web 连接不支持工作区接口的旧网关时 SHALL 隐藏该入口或提示需重新启动网关，其他功能正常。文件树、查看器与改动列表的加载失败 SHALL 在栏内给出可重试的错误提示，MUST NOT 影响聊天、审批、提问等主流程。

#### Scenario: 旧网关
- **WHEN** Web 连接到不支持工作区接口的旧网关
- **THEN** 不显示工作区入口，或显示需要重新启动网关的提示，聊天与其他面板正常

#### Scenario: 读取失败
- **WHEN** 文件读取因权限不足或超时失败
- **THEN** 栏内显示错误与重试入口，聊天流与输入框不受影响
