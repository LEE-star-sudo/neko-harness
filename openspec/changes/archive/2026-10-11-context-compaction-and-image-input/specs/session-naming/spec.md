# Spec Delta

## ADDED Requirements

### Requirement: 图片首问的名称回退

首次输入含图片时，系统 SHALL 优先使用文字作为首问摘要；仅图片输入 SHALL 使用稳定的图片消息占位而非空会话占位。首轮完整回答后的命名 SHALL 继续使用非思考的文字请求，输入仅含首问文字或图片消息占位及回答正文，不包含图片数据、临时路径或额外视觉总结。

#### Scenario: 仅图片消息

- **WHEN** 用户仅发送图片，首轮回答尚未完成或命名失败
- **THEN** 两端显示可辨识的图片消息占位；成功回答后可根据占位和回答正文生成标题，不因文字为空跳过整个命名流程

#### Scenario: 图文消息与压缩

- **WHEN** 首问包含文字和图片，或之后执行压缩
- **THEN** 首问文字用于摘要和命名，图片不进入标题请求；压缩不重启命名或更改已有标题
