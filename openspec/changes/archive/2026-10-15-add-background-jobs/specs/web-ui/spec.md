# Spec Delta

## ADDED Requirements

### Requirement: Web 后台任务面板
Web SHALL 在会话界面提供后台任务面板：顶栏在当前会话存在运行中 job 时显示数量入口；面板列出任务（标题或命令、状态、运行时长或退出码），选中后显示命令、工作目录、状态及输出尾部，运行中自动跟随新输出，向上查看后不强制滚到底部并提供回到底部入口。运行中任务 SHALL 有停止按钮，停止期间防止重复提交。面板 MUST NOT 提供启动任务的入口，打开与关闭不改变输入框草稿、附件与历史浏览状态。无任务时入口隐藏或显示空状态，且在 375、768、1440、1920 像素宽度下无横向溢出。

#### Scenario: 查看与停止
- **WHEN** 用户从顶栏打开面板，选中运行中的 `uv run` 任务并点击停止
- **THEN** 输出详情持续更新直到状态变为 stopped，停止按钮随之消失，其他任务不受影响

#### Scenario: 长输出与滚动
- **WHEN** 任务输出持续增长，用户向上查看较早内容
- **THEN** 不强制滚到底部，提供回到底部入口；输出显示与服务端保留的尾部一致，截断处有标注

#### Scenario: 响应式布局
- **WHEN** 用户在 375 与 1440 像素宽度打开含多个任务的面板
- **THEN** 列表与详情均可读，命令与输出可折行或滚动，无横向溢出

#### Scenario: 旧网关
- **WHEN** Web 连接不支持 job 的旧网关
- **THEN** 不显示任务入口或显示需要重新启动网关的提示，其他功能正常

### Requirement: Web 后台任务回报呈现
job 回报输入 SHALL 在 transcript 中以系统提示卡呈现（jobId、标题、状态、退出码，输出尾部默认折叠，可展开），MUST NOT 显示为用户消息气泡；终态变化时卡片状态与面板一致。

#### Scenario: 回报卡
- **WHEN** 后台任务退出并向会话回投回报
- **THEN** 消息列表出现系统提示卡，可展开查看输出尾部，随后显示模型的新一轮回答，用户气泡数量不变

#### Scenario: 刷新后一致
- **WHEN** 用户刷新页面或切换会话再回来
- **THEN** 回报仍以系统提示卡出现，且面板中的任务状态与卡片一致
