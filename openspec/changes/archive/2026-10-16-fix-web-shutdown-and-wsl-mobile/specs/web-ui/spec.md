## MODIFIED Requirements

### Requirement: Web 手机配对设置

Web 设置 SHALL 新增「手机配对」入口，在电脑本机提供局域网访问开关、地址选择、实际监听状态、限时二维码、可复制的配对文本和刷新操作，延续当前设置风格。默认只给出「手机与电脑连接同一局域网，在 App 中扫码」等简短指引；必要时提示防火墙及网络隔离，并说明关闭拉起 gateway 的前端会同时停止手机访问。运行在 WSL 时，候选地址 SHALL 为 Windows 局域网地址，并标明访问经由 Windows 侧中继；中继状态与失败原因须可见。配对能力不可用或用户从非本机访问时 MUST 明确说明，不显示可操作的管理控件。

#### Scenario: 本机开启与扫码
- **WHEN** 用户在电脑打开手机配对设置并启用入口
- **THEN** 启动成功后显示实际地址、二维码及到期状态，手机扫码即可配对；关闭或失败时不继续显示有效二维码

#### Scenario: 多网卡与过期
- **WHEN** 电脑存在多个可用局域网地址，或二维码过期
- **THEN** 用户可选择供手机访问的地址；过期二维码明确失效并提供刷新，不把回环或无效地址当成手机可达地址

#### Scenario: 旧网关或远程 Web
- **WHEN** 当前 gateway 尚不支持配对管理，或用户经局域网地址远程打开 Web
- **THEN** 显示更新/重新启动电脑端或在电脑本机打开设置的指引，不尝试绕过管理边界，不影响普通聊天

#### Scenario: WSL 下选择地址
- **WHEN** 用户在 WSL 中运行 neko web 并打开手机配对设置
- **THEN** 地址下拉只列出 Windows 局域网地址而非 WSL 内部 172.x 地址，开启后显示该地址、中继状态与二维码；关闭手机访问或中继失败时二维码消失并说明原因
