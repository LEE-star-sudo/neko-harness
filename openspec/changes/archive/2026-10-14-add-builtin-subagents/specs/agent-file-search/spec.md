## Purpose

为主 agent 和内置子 agent 提供统一的只读文件发现与文本内容搜索，使模型无需任意 shell 就能从未知文件位置定位代码与证据，并获得有界、可取消且错误语义明确的结果。

## ADDED Requirements

### Requirement: 文件发现工具
系统 SHALL 提供模型可调用的文件发现工具，支持目录、名称匹配和有界结果，返回可直接读取的路径及文件类型。相对输入 SHALL 根据实际调用会话的工作目录解析，默认遵循工作区忽略规则，不依赖用户另装 fd。枚举 SHALL 沿用 Pi 跳过不可读目录项的语义，并在结果中明确说明；完整仅指原生枚举返回的范围。主 agent 和具备该工具的子 agent SHALL 使用相同接口。

#### Scenario: 不同工作区调用
- **WHEN** gateway 启动目录与子 agent 工作目录不同，子 agent 查询文件
- **THEN** 查询使用子 agent 工作目录，返回可直接传给读取工具的路径

#### Scenario: 平台和忽略规则
- **WHEN** 工作区包含带空格、中文、嵌套路径或被忽略目录，运行于 Windows/macOS/Linux
- **THEN** 有效文件均可定位，返回路径分隔符统一且忽略规则一致，不要求额外安装 fd

### Requirement: 内容搜索工具
系统 SHALL 提供只读文本搜索，首版支持字面字符串、大小写选项、搜索目录和文件名筛选，返回文件路径、行号与有界上下文。工具 MUST NOT 接受任意 shell 命令；二进制及超出处理限制的文件 SHALL 跳过并报告不完整性，不伪装为完整无匹配。

#### Scenario: 搜索到读取闭环
- **WHEN** explore 搜索一个函数名并读取命中文件附近内容
- **THEN** 搜索返回有效路径及准确行号，原生读取工具能够据此读取证据

#### Scenario: 复杂输入
- **WHEN** 搜索文本含引号、反引号、美元符号或 shell 元字符
- **THEN** 按字面文本搜索，不执行命令或写入文件

### Requirement: 搜索资源与错误反馈
文件发现与内容搜索 SHALL 限制扫描量、单文件字节数、结果条数、输出字节数及执行时间，支持调用取消。结果 SHALL 区分完整无匹配、部分结果、读取失败和超时；截断 SHALL 明示并指导缩小目录或条件。查询 MUST NOT 修改被搜索文件。

#### Scenario: 截断与无匹配
- **WHEN** 扫描预算耗尽且尚无命中，或结果超过输出限制
- **THEN** 返回不完整或截断标记，而非完整无匹配或静默丢弃

#### Scenario: 停止与失败
- **WHEN** 调用取消、目录消失、权限不足或搜索超时
- **THEN** 及时释放查询资源，给出准确结果状态，不阻止其他会话继续运行
