## MODIFIED Requirements

### Requirement: 会话目录
系统 SHALL 维护会话目录（创建、列出、删除会话），目录变化 MUST 实时推送给已连接的前端。每个条目 SHALL 包含持久化的工作区、标题、首问摘要、创建时间、最近消息时间与最近使用信息，并提供会话模型和运行状态，以支持前端展示、筛选和恢复。目录保持全局可见，工作区筛选不构成权限隔离。子 agent 会话 SHALL 仅通过所属主会话的委派记录访问，不出现在普通会话目录。

#### Scenario: 新会话广播
- **WHEN** 任一前端创建会话
- **THEN** 所有已连接前端在目录更新中收到该会话及其工作区

#### Scenario: 最近使用更新
- **WHEN** 会话被成功激活或接受用户输入
- **THEN** 最近使用信息被持久更新并推送，网关重启后仍可据此排序；仅后台输出不改变最近使用顺序；最近使用时间与最近消息时间分别维护

#### Scenario: 子会话不进入目录
- **WHEN** 主 agent 创建子会话并持续运行或结束后重连
- **THEN** 普通会话目录不新增该子会话，原有普通会话与用户分叉仍正常展示

## ADDED Requirements

### Requirement: 子 agent 观察与停止服务
网关 SHALL 提供绑定主会话的委派列表、按需子会话详情订阅、历史读取、图片读取及单独停止能力。详情 SHALL 包含与主会话同类的持久消息和实时调用数据，保留原有错误、截断及图片传输规则；接口 MUST 校验主子归属，不允许借详情句柄提交输入、修改配置或启动新子任务。

#### Scenario: 双端观察
- **WHEN** Web 与 TUI 同时查看同一子 agent，一端停止它
- **THEN** 两端获得相同最终状态及已产生历史，主会话与其他子任务继续按原生语义运行

#### Scenario: 旧引用与越界
- **WHEN** 客户端切换主会话后旧详情返回，或请求不属于该主会话的子会话与图片
- **THEN** 旧响应不覆盖新选择，非法读取或停止被拒绝，不触及无关会话

#### Scenario: 重连与资源释放
- **WHEN** 用户关闭详情、断线或重新连接
- **THEN** 未使用的详情订阅及读取资源释放，执行不中断；重连恢复真实记录而不重新派发任务

#### Scenario: 大量历史
- **WHEN** 子 agent 产生很长工具日志或多个子 agent 同时流式运行
- **THEN** 列表仅推送摘要，详细历史按需有界加载，不每次把所有子会话完整历史广播给所有客户端

### Requirement: 主会话归档与分叉的委派边界
归档主会话 SHALL 先停止所属未完成委派，再隐藏其访问入口；用户分叉主会话 MUST NOT 复制正在执行的委派。分叉历史中的委派卡 SHALL 可只读查看分叉点之前已有的记录，不授予控制原任务的能力，也不把原任务后续活动或成本计为新分叉任务。

#### Scenario: 归档运行中主会话
- **WHEN** 用户归档仍有运行或排队子任务的主会话
- **THEN** 所属任务结束取消流程后主会话隐藏，不留下继续执行却无法查看的子任务

#### Scenario: 分叉已有委派
- **WHEN** 用户从含委派卡的主会话创建分叉
- **THEN** 历史卡标识为原会话记录，查看仅限分叉点已有内容，不能停止原任务或复制派发
