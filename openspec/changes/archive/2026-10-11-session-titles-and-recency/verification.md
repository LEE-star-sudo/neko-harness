# 实施与验收记录

## 实现范围

- 新版会话元数据与会话原子创建；消息时间与访问恢复时间独立。分叉名称原子复制，不继承命名任务或费用。
- 首问与成功最终回答按 submission/answer 关联；后台同模型非思考命名、无工具、有界输入、单行标题及摘要降级。
- 命名并发 2、每次超时 20 秒、总计最多 2 次尝试，间隔 2 秒；重开保留预算，归档/关闭取消，迟到结果丢弃。
- 命名费用独立持久化，合入会话、全局及前端投影；Unix/WS 共享完整目录，即使未 attach 也能收到标题。
- Web 两行侧栏、共享名称回退、摘要/标题/ID 搜索与相对时间。触屏操作菜单也展示完整标题、ID、时间；弹层在绘制前定位。
- TUI `/sessions` 与 `/session` 按消息时间倒序，显示标题、时间、当前标记与详情；后台重排保持 ID 选择，移除时回退相邻项。

## 自动化验证

`bun test --conditions=neko-source --isolate`：73 项测试全部通过、352 条断言，23 个测试文件，约 49 秒。覆盖临时 SQLite 重开、旧格式拒绝且不删数据、重复 requestId、首轮工具/steer/follow-up、空回答与中止、标题失败费用、并发上限、超时及恢复、归档迟到结果、模型不支持 off、双传输后台目录、断线恢复和工作区范围。

DeepSeek 测试只拦截本地 fetch 并返回模拟 SSE：捕获到聊天 `thinking: { type: "enabled" }`、标题 `thinking: { type: "disabled" }`，标题没有 tools，原会话仍为 high。没有访问真实模型或读取/输出真实密钥。超时用例实际等待超过 42 秒，验证两次 20 秒预算和 2 秒重试间隔后停止。

TUI 使用真实布局引擎验证 120×40、80×24、60×16 的长标题、长列表、输入区与常驻状态栏；按键测试覆盖 Kitty press/repeat/release、搜索中更新、按 ID 保持选择、相邻回退、关闭后迟到更新。面板关闭和应用退出路径均清理定时器，应用退出释放目录订阅。

## 浏览器与双端验收

独立临时 SQLite、随机端口、模拟 provider 创建 28 条长标题/重复标题会话，再从 Web 创建会话并发送首问；命名为 Test session 后，输入框仍保留“保留这份草稿”。摘要搜索返回 9 条结果，不匹配搜索显示空态；归档确认显示完整名称及 ID。移动端 hasTouch/isMobile 上下文验证行操作菜单，无横向溢出；Escape 后焦点回到操作按钮。

同一临时网关的 WebSocket 目录接入 TUI 布局引擎，显示相同 Test session 标题、最近消息顺序与 ID。TUI 记录是布局引擎输出，不是原生终端屏幕截图。
