# Proposal

## Why

Web 当前平铺全局会话，新建会话使用网关默认目录，首次连接及归档后的回退也可能跨工作区，与已落地的 Harness/TUI 工作区语义不一致。侧栏缺少稳定的工作区入口，按钮与弹层交互需要收敛为清晰、紧凑的导航体验。

## What Changes

- 独立持久化工作区，以宿主真实绝对目录为身份；空工作区与最后一个会话归档后的工作区仍保留。
- 在 Web 内通过宿主目录选择面板添加工作区，支持逐层浏览、返回上级、路径输入、名称过滤与隐藏目录开关，服务端验证并按真实目录去重。
- Web 采用“工作区切换器 → 当前工作区会话”结构；新建显式绑定当前工作区，恢复、切换、归档和重连不隐式跳到其他工作区。
- 默认进入 Web 启动目录对应的工作区，切换时恢复该工作区最近使用的会话，无会话时展示新建入口。
- 侧栏与顶栏采用 Notion 式中性色、紧凑导航和轻量操作菜单，聊天区保留蓝粉白主题；完善桌面折叠、移动端抽屉、焦点管理、加载及错误反馈。
- 不包含系统原生文件夹窗口、目录上传、文件管理器、工作区删除/重命名、会话跨工作区移动、账户权限体系或聊天区主题重做。

## Capabilities

### New Capabilities

- `workspace-management`：独立持久化工作区目录、宿主文件夹浏览与添加、目录身份去重、已有会话归属接入及多客户端目录同步。

### Modified Capabilities

- `web-ui`：工作区内会话生命周期、目录选择流程、响应式导航与操作反馈，以及中性导航区域和原有聊天主题的边界。

## Impact

- core：在现有存储中新增工作区记录，复用目录规范化逻辑，创建与分叉会话登记工作区。
- gateway：增加工作区目录订阅、添加和宿主目录浏览服务，保留现有全局会话目录及工具权限语义。
- web：更新浏览器契约、连接管理、store、侧栏/顶栏及局部样式；`/api/info` 增加 Web 启动工作区信息。
- 测试覆盖持久化、协议一致性、目录选择、异步切换/重连、多前端更新和实际浏览器交互；README 与规格正文保持中文。
- 兼容上次变更产生的工作区会话存储，不清空历史、不改写已有会话目录；不升级 Pi、不改动锁版本或 reference。
