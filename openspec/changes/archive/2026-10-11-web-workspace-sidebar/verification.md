## 浏览器与集成验证

使用独立临时 SQLite、Unix socket、随机本地端口和 faux provider。没有使用真实模型密钥或清除用户历史。

- 网关启动于 A，Web 启动于 B 并复用该网关；初次打开及刷新均进入 B。
- 从 Web 目录面板登记 C，在 C 新建会话，真实 `bash pwd` 工具输出 C。通过 TUI 的连接入口 attach 同一会话，读取到相同的 cwd 和 workspaceRoot。
- 归档 C 的最后一个会话后保持 C 空态；重启网关后，C 仍在工作区列表中，当前页面仍停留于 C。
- 同名工作区通过完整路径区分；会话搜索无结果显示明确空态。重复添加已有工作区不生成重复项。
- 目录面板验证了父级导航、完整路径输入、隐藏目录、名称过滤、超过 100 项后的加载更多、错误路径恢复、重复添加、延迟响应后取消不重开弹层。
- 使用 35 个以上会话、105 个以上目录和长目录名，在 1440、1024、768、375 像素宽度检查导航及弹层。会话菜单在滚动列表底部仍可见，目录面板没有横向溢出，底部操作固定可用。
- 检查桌面侧栏折叠、移动端默认关闭、抽屉与弹层叠放、Tab 循环、方向键、Escape、取消和焦点恢复。触屏浏览器上下文验证操作按钮常显、点击归档以及断线后错误保留在确认弹层内。
- 聊天区保留粉蓝主题和工具卡片。对实际 Markdown 组件执行浏览器消毒回归，确认粗体正常渲染，`script` 和 `onerror` 被移除且没有执行。

验收中修复了目录初始响应覆盖已编辑路径、长目录名撑宽 fieldset、Tab 焦点移出弹层的问题；嵌套弹层使用共享计数恢复背景滚动，避免卸载顺序导致残留锁定。
