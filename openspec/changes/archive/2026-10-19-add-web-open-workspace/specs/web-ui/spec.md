# Spec Delta

## ADDED Requirements

### Requirement: Web 顶栏工作区图标入口
顶栏的工作区入口 SHALL 是图标按钮而非文字药丸：使用右侧栏图标，agent 改动文件数大于 0 时以角标显示，超过两位数时显示上限形式。按钮 MUST 保留可访问名称（含改动文件数）、`aria-expanded` 与悬停提示，开合与焦点回归行为不变，并在旧网关上继续隐藏。

#### Scenario: 有改动
- **WHEN** agent 已修改 3 个文件且工作区栏关闭
- **THEN** 顶栏显示右侧栏图标，角标为 3，朗读名称为「工作区，3 个改动文件」，点击打开右侧栏

#### Scenario: 无改动
- **WHEN** 当前会话没有改动文件
- **THEN** 图标无角标，朗读名称为「工作区」

### Requirement: Web 打开工作区分体按钮
Web 顶栏 SHALL 在工作区入口之前提供「打开工作区」分体按钮：主按钮用上次选择的目标打开当前会话的工作区根目录，下拉菜单列出「VS Code」与文件管理器（名称随平台），每项显示图标。主按钮与菜单项 MUST 有可朗读名称与悬停提示（如「用 VS Code 打开」），菜单可用键盘打开与操作，Escape 关闭并把焦点还给触发控件。当前无会话、连接未就绪或本机能力不可用时 SHALL 隐藏或置灰。

#### Scenario: 默认打开
- **WHEN** 用户首次点击主按钮
- **THEN** 当前会话工作区在 VS Code 中打开，主按钮图标为 VS Code

#### Scenario: 切换目标
- **WHEN** 用户展开下拉并选择文件管理器
- **THEN** 工作区在文件管理器中打开，主按钮之后改为文件管理器图标

#### Scenario: 键盘操作
- **WHEN** 用户用键盘聚焦下拉触发器并按 Enter
- **THEN** 菜单打开且焦点进入菜单，方向键选择，Enter 执行，Escape 关闭并回到触发控件

### Requirement: Web 顶栏窄屏布局
窄屏下顶栏 SHALL 在 375 像素宽度无横向溢出：打开工作区入口折叠进更多菜单或收为仅图标，且不遮挡会话标题、连接状态与导出入口。

#### Scenario: 小屏幕
- **WHEN** 在 375 像素宽度查看顶栏
- **THEN** 打开工作区、工作区栏与导出入口均可见可点或位于菜单内，无重叠与横向溢出
