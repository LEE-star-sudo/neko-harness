# Spec Delta

## MODIFIED Requirements

### Requirement: 工作区文件候选

系统 SHALL 为 @ 引用提供工作区文件与目录候选，支持空查询、名称模糊搜索和相对目录定位，安装后无需额外安装文件发现工具。候选 MUST 使用工作区相对路径，不提升到 Git 根；包含合法隐藏项、排除 .git，遵守工作树的 Git 忽略规则，不读取 fd 专用或 .ignore 文件。真实目标 MUST 位于当前工作区；该限制不改变工具访问权限。枚举不完整与候选过多 SHALL 分开标识，前者不得伪装为无匹配。

#### Scenario: 定位与搜索

- **WHEN** 用户在工作区 B 输入 @、@runtime 或 @packages/core/
- **THEN** 分别展示 B 的直接子项、名称匹配结果或指定目录内候选，目录可辨识，同名文件可通过父路径区分

#### Scenario: 忽略与越界

- **WHEN** 工作区包含 Git 忽略项、隐藏项、.git、外部符号链接，或用户输入越出根目录的路径
- **THEN** 忽略项、.git 和真实目标在工作区外的条目不成为候选；合法隐藏项可见，越界查询明确拒绝

#### Scenario: 大目录与失效目录

- **WHEN** 候选超过返回限制、枚举达到资源上限、查询超时或工作区已删除
- **THEN** 查询有界结束，分别反馈候选过多、不完整、超时或目录失效，可缩小范围或重试，不静默切换目录

#### Scenario: 无外部工具安装

- **WHEN** 支持平台正常安装 neko 后，宿主 PATH 中没有 fd 或 fdfind
- **THEN** 两端仍可查询文件候选，不要求安装工具或建立命令别名

#### Scenario: 不完整索引中的查询

- **WHEN** 工作区枚举被截断，当前索引没有匹配，用户随后指定包含目标的子目录
- **THEN** 初次查询明确提示结果不完整；后续直接查询该子目录，不因根索引截断永久漏掉目标

#### Scenario: 忽略规则来源

- **WHEN** Git 工作树配置父级/子级 .gitignore、info/exclude 或全局 Git excludes，另有 .ignore/.fdignore；或非 Git 目录存在 .gitignore
- **THEN** 只沿用原生 Git 忽略语义；.ignore/.fdignore 不改变候选，非工作树的 .gitignore 不作为忽略规则

## ADDED Requirements

### Requirement: 文件候选缓存与刷新

文件候选缓存 SHALL 有界、按工作区及目录隔离，由多个客户端共享。文件创建、删除、重命名和忽略变化 SHALL 使后续查询刷新；事件未捕获时，缓存最多有效 30 秒，到期后的查询 MUST 重建。移除工作区、空闲淘汰及关闭 SHALL 回收观察和扫描资源。取消或失效查询 MUST 不覆盖新请求，单客户端取消不得破坏其他客户端正在等待的共同查询。

#### Scenario: 文件与忽略变化

- **WHEN** 已查询的目录新增、删除或重命名文件，或修改忽略规则后再次查询
- **THEN** 已观察变化使相关缓存失效；未观察到的变化在 30 秒有效期结束后的查询刷新，不永久复用旧候选

#### Scenario: 多客户端与取消

- **WHEN** TUI/Web 同时查询同一目录，其中一端取消、切换会话或关闭候选
- **THEN** 另一端的查询仍可完成，旧响应不覆盖新工作区或恢复已关闭面板

#### Scenario: 长期运行与关闭

- **WHEN** 用户连续查询多个大工作区，随后移除工作区、停止查询或关闭网关
- **THEN** 缓存按上限淘汰，空闲与失效资源回收，关闭后没有遗留观察、扫描或辅助进程

#### Scenario: 观察或辅助进程失效

- **WHEN** 文件观察失效、报告漏事件，或文件发现辅助进程退出
- **THEN** 相关缓存不能继续充当有效新快照；观察失败仍可过期刷新，进程故障明确反馈且后续查询可重试，不终止普通聊天
