# Spec Delta

## ADDED Requirements

### Requirement: 默认模型同步

网关 SHALL 为 TUI/Web 提供服务器级默认模型的状态订阅、设置与清除能力，无需 attach 会话。状态 SHALL 包含生效的默认模型及其来源（命令行、已保存、配置文件、内置默认）。设置 SHALL 先校验再持久化：只接受目录内已启用 provider 的已知模型，不要求已具备凭据；持久化成功后 SHALL 通知所有已连接前端，断线重连 SHALL 恢复最新状态。新增该服务 SHALL 递增链路协议版本，沿用"协议版本不同即被明确拒绝"的既有约束，不提供回退。

#### Scenario: 双端同步

- **WHEN** Web 把某模型设为默认且 TUI 已连接
- **THEN** 两端收到相同的新默认模型与来源"已保存"，之后任一端新建的会话使用该模型，无需重启

#### Scenario: 逐项来源与清除回退

- **WHEN** 保存值存在时清除它，或从未保存时读取状态
- **THEN** 清除后来源回落为命令行、配置文件或内置默认并广播；未保存时来源如实反映命令行、配置文件或内置默认

#### Scenario: 无会话与重连

- **WHEN** 未 attach 会话的客户端读取默认模型，或修改期间断线后重连
- **THEN** 可读取并修改设置，重连显示服务端最终状态，不因旧响应覆盖新状态

#### Scenario: 非法提交与持久化失败

- **WHEN** 提交未知模型、未启用 provider 的模型，或持久化失败
- **THEN** 操作被拒绝并返回可识别错误，不发布成功状态，原默认模型保持不变

#### Scenario: 协议版本递增

- **WHEN** 仍运行上一协议版本的网关被新版 TUI/Web 连接，或旧版客户端连接新网关
- **THEN** 连接以可识别的协议不兼容原因被拒绝，不进入部分可用状态
