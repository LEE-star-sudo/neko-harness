# Spec Delta

## ADDED Requirements

### Requirement: Web 默认模型设置

Web 模型选择器 SHALL 标识当前默认模型，并对可选模型提供「设为默认」操作；已是默认的模型可取消默认。未配置 Key 而不可选的模型 MUST NOT 提供该操作。操作结果 SHALL 即时反映在标识上并与其他前端保持一致；默认模型 SHALL 只影响新建会话，不改变当前会话模型。

#### Scenario: 设为默认

- **WHEN** 用户在选择器中对某可选模型执行「设为默认」
- **THEN** 该模型显示默认标识，之后新建的会话默认使用该模型，当前会话模型不变

#### Scenario: 取消默认

- **WHEN** 用户对当前默认模型取消默认
- **THEN** 标识消失，之后新建的会话按配置文件或内置默认解析

#### Scenario: 无 Key 模型

- **WHEN** 选择器中存在已启用但未配置 Key 的模型
- **THEN** 该条目保持不可选，且不显示「设为默认」入口

#### Scenario: 跨端一致

- **WHEN** TUI 修改默认模型后用户打开 Web 选择器
- **THEN** Web 显示同一默认模型标识，无需刷新页面
