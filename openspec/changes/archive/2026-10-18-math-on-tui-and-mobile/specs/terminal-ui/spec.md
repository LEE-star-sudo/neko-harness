# Spec Delta

## ADDED Requirements

### Requirement: TUI 公式渲染

TUI SHALL 在所有 Markdown 渲染处（助手回答、已保存思考、用户消息、技能预览）把 `$..$`、`$$..$$`、`\(..\)`、`\[..\]` 中的 LaTeX 渲染为终端可读的 Unicode 文本：常见希腊字母、运算符、上下标、根号、分式与求和/积分等多行排版可读，块级公式独占行。代码块与行内代码中的 `$` MUST NOT 被当作公式；货币与变量写法（如 `$5 and $10`、`$HOME`）MUST 保持原文。

#### Scenario: 行内与块级公式

- **WHEN** 助手回答包含 `$E=mc^2$` 与独占一段的 `$$\frac{a+b}{c}$$`
- **THEN** 前者在句中显示为 `E = mc²`，后者以带分数线的多行文本显示，界面不出现 `$` 定界符与原始 LaTeX 源码

#### Scenario: 括号定界符

- **WHEN** 回答使用 `\(\alpha+\beta\)` 与 `\[x^2\]`
- **THEN** 两者按公式渲染，与 `$` 写法效果一致

#### Scenario: 表格与列表中的公式

- **WHEN** 公式出现在 Markdown 表格单元格、列表项或引用中
- **THEN** 公式正常渲染，表格对齐与列表缩进不被破坏

#### Scenario: 货币、变量与代码

- **WHEN** 回答包含 `价格 $5 到 $10，变量 $HOME`、行内代码 `$x$` 或围栏代码块中的 `$x$`
- **THEN** 这些内容按原文显示，不被渲染为公式

### Requirement: TUI 公式降级

TUI SHALL 在公式不受支持或无法解析时按原文（含定界符）显示，不得使整条消息渲染失败或丢失其他内容。流式输出中尚未闭合的公式 MUST 在闭合前保持原文，闭合后转为公式。

#### Scenario: 不支持的公式

- **WHEN** 回答包含 `$$\textcolor{red}{x}$$` 等渲染器不支持的公式及其他正常段落
- **THEN** 该公式按原文显示，其余段落、代码块与公式正常渲染

#### Scenario: 流式未闭合公式

- **WHEN** 流式回答已到达 `$$\frac{a+b` 但尚未收到结束定界符
- **THEN** 界面不报错且显示原文，收到结束定界符后该段转为公式
