# Spec Delta

## ADDED Requirements

### Requirement: 公式括号定界符

Web 的 Markdown 渲染 SHALL 除 `$..$` 与 `$$..$$` 外，也把 `\(..\)` 渲染为行内公式、把 `\[..\]` 渲染为块级公式，复用「数学公式渲染」与「非法公式降级」的全部规则（消毒、降级为原文、未闭合保持原文）。代码块与行内代码中的 `\(`、`\[` MUST 保持原文；`\\(`、`\\[`（转义反斜杠）MUST NOT 被当作定界符。

#### Scenario: 行内与块级括号公式

- **WHEN** 模型回答包含 `速度 \(v = \frac{s}{t}\)` 与独占一段的 `\[\sum_{i=1}^{n} i\]`
- **THEN** 前者以行内公式、后者以居中块级公式呈现，界面不出现 `\(`、`\[` 定界符与原始 LaTeX 源码

#### Scenario: 代码中的括号定界符

- **WHEN** 回答的行内代码或代码块包含 `\(x\)`、`\[x\]`
- **THEN** 内容按原样显示为代码，不被渲染为公式

#### Scenario: 非法与未闭合括号公式

- **WHEN** 回答包含 `\(\frac{a\)` 或流式中尚未收到 `\]` 的 `\[\sum_{i=1}`
- **THEN** 该部分按原文显示且不影响其余内容，闭合且合法后转为公式

#### Scenario: 括号公式消毒

- **WHEN** 括号公式中夹带 HTML 标签、脚本或 `\href`、`\url`
- **THEN** 界面不执行任何脚本，不产生可点击的外部链接
