# Spec Delta

## ADDED Requirements

### Requirement: Web 手机配对设置

Web 设置 SHALL 新增「手机配对」入口，在电脑本机提供局域网访问开关、地址选择、实际监听状态、限时二维码、可复制的配对文本和刷新操作，延续当前设置风格。默认只给出「手机与电脑连接同一局域网，在 App 中扫码」等简短指引；必要时提示防火墙及网络隔离，并说明关闭拉起 gateway 的前端会同时停止手机访问。配对能力不可用或用户从非本机访问时 MUST 明确说明，不显示可操作的管理控件。

#### Scenario: 本机开启与扫码
- **WHEN** 用户在电脑打开手机配对设置并启用入口
- **THEN** 启动成功后显示实际地址、二维码及到期状态，手机扫码即可配对；关闭或失败时不继续显示有效二维码

#### Scenario: 多网卡与过期
- **WHEN** 电脑存在多个可用局域网地址，或二维码过期
- **THEN** 用户可选择供手机访问的地址；过期二维码明确失效并提供刷新，不把回环或无效地址当成手机可达地址

#### Scenario: 旧网关或远程 Web
- **WHEN** 当前 gateway 尚不支持配对管理，或用户经局域网地址远程打开 Web
- **THEN** 显示更新/重新启动电脑端或在电脑本机打开设置的指引，不尝试绕过管理边界，不影响普通聊天

### Requirement: Web 已配对设备管理

手机配对页 SHALL 显示已配对设备的名称、连接状态与最后连接时间，提供明确的单设备撤销操作及结果反馈；证书临近到期时 SHALL 提示，并提供需二次确认的重新生成证书操作（撤销全部设备）。撤销 SHALL 提示该设备无法继续连接、已受理任务仍继续，成功后更新实际设备状态；操作失败或迟到结果不得冒充成功。页面 MUST 支持键盘、触屏及现有主题，管理秘密不得出现在聊天内容或常规调试输出中。

#### Scenario: 撤销与同步
- **WHEN** 用户撤销在线手机并确认
- **THEN** 页面显示授权已撤销、手机断开，其他设备和电脑会话继续工作；刷新页面不恢复已撤销授权

#### Scenario: 管理失败与访问
- **WHEN** 撤销失败，或用户在 375px/1440px 宽度使用键盘访问管理页
- **THEN** 失败保留真实状态并可重试，二维码和设备列表不溢出，开关、刷新、撤销均有可访问名称与焦点
