# 修复与复盘记录

核对本地 Pi 参考实现：普通 resource-loader 显式 reload，durable 桥按目录加载一次；未采用 mtime/ctime/size 指纹。neko 为保持下一请求自动更新，每次重新读取资源，请求内共享 Promise 快照，不保留跨请求文件内容缓存。

修复权限变化、不可调用技能名称、frontmatter 分隔行与映射校验；加载/解析失败提供不含正文的诊断，相同工作区连续相同诊断去重。已知技能展开失败沿用 Pi 的原文回退，额外报告原因。超过 64 KiB 的项目指令提示风险但不截断，此阈值为 neko 自定义，压缩不负责缩短系统指令。

验证：
- 完整回归：162 pass、0 fail、858 assertions、47 files。
- check、build、两个待提交变更的 OpenSpec strict 校验通过。
- 回归涵盖权限撤销/恢复、文件删除后 durable system section 清除、严格 frontmatter、名称校验、诊断去重与不含正文、技能修改后的 requestId 重试。
- 本机临时目录 100 个约 1 KB 技能文件，20 次加载，中位约 6.98 ms、最大约 18.49 ms。仅代表本机小样本，不推断网络盘或大技能库。
- 临时测试目录由测试清理；临时日志删除，不归档截图。

保留边界：诊断在宿主日志中，尚无诊断 UI；加载无跨文件事务快照。显式技能正文以准入时版本持久化，生成阶段元数据可观察到后续编辑；二者共享发现规则，不承诺跨时刻版本一致。
