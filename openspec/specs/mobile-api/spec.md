# mobile-api Specification

## Purpose
为原生手机客户端提供独立版本、经过设备认证且有界的会话控制接口，复用电脑侧现有持久运行和前端数据语义，支持流式查看与可靠操作而不要求手机实现电脑内部远程对象协议。

## Requirements

### Requirement: 移动 API 认证与兼容

移动 API SHALL 在返回工作区、会话或内容前验证设备授权，并在开放业务操作前校验独立于产品发布版本的 API 兼容性。握手 SHALL 返回电脑身份、运行版本、API 版本、能力及传输限制。不兼容 MUST 明确指出需更新电脑或 App，不无限重连；无效或已撤销凭据不得得到业务数据。

#### Scenario: 不同发布版本
- **WHEN** App 与电脑发布版本不同但移动 API 兼容
- **THEN** 可继续使用已支持的功能，不要求双方产品版本号完全一致

#### Scenario: 未授权或协议不兼容
- **WHEN** 手机未配对、授权已撤销或 API 不兼容
- **THEN** 业务读取和控制均不就绪，返回可区分的授权或升级提示，不泄露会话内容

### Requirement: 移动控制能力边界

移动 API SHALL 只开放已登记工作区列表、会话列表/创建/查看、文字提交、显式停止、子 agent 查看/停止、待决命令审批与会话历史媒体读取。接口 MUST 校验所有参数及对象归属，不提供任意内部服务调用、宿主路径读取、直接 Bash 执行、凭据修改、模型配置、会话归档/分叉、后台任务、技能安装、配对管理、远程升级或手机附件上传能力。新增移动 API MUST NOT 修改现有桌面客户端使用的服务契约。

#### Scenario: 已登记工作区使用
- **WHEN** 手机在已登记工作区 B 中创建并选择主会话
- **THEN** 与 TUI/Web 使用同一目录、模型默认配置和持久会话，工具默认目录来自 B；工作区选择不声称构成工具文件访问沙箱

#### Scenario: 越权方法与引用
- **WHEN** 手机调用未开放方法、使用未知工作区或读取不属于目标会话的图片/子 agent
- **THEN** 在副作用或内容读取前明确拒绝，不落回网关启动目录，不解析为任意宿主路径

### Requirement: 移动快照与观察资源

连接及 attach SHALL 以首个有效快照到达作为对应操作就绪条件。状态更新 MUST 绑定连接代次、订阅及会话身份；切换、detach 或重连后旧响应不得覆盖新视图或继续操作旧 attachment。断开 SHALL 释放该客户端订阅、查询和引用，不停止共享会话或其他客户端观察。

#### Scenario: 快速切换会话
- **WHEN** 手机切换会话后旧会话的订阅或控制响应迟到
- **THEN** 不覆盖新视图或误向新会话提交，旧引用调用明确失败

#### Scenario: 重连与多前端
- **WHEN** 手机断线期间电脑继续执行，随后手机重新连接
- **THEN** 取得最新快照并按需补历史，不逐事件重放，也不创建第二份 Agent 任务；其他前端持续工作

### Requirement: 移动历史与内容有界传输

主/子会话 SHALL 返回最近记录并支持稳定分页补齐较早历史，保留持久消息顺序、工具配对及轮次。过大正文和工具结果 SHALL 提供明确的按需分块读取，不静默截断。图片只在状态中携带描述，按需有界读取。协议 SHALL 公布帧、页面、请求并发和发送缓冲限制，慢连接或无效帧只影响该连接。

#### Scenario: 长历史和长工具结果
- **WHEN** 手机打开含大量主/子记录或单个超长工具结果的会话
- **THEN** 初始状态与每个传输单元遵守限制，用户可以补齐历史和完整结果，无重复或丢失已保存内容，原工具截断标记仍可辨识

#### Scenario: 持久图片
- **WHEN** 手机读取主/子历史图片且原宿主文件已经消失
- **THEN** 从会话持久附件读取；无效条目或内容位置被拒绝，不暴露任意文件

#### Scenario: 慢客户端
- **WHEN** 手机持续无法消费状态更新或发送超限帧
- **THEN** 服务端合并可合并状态或关闭该连接，不无限缓存，不阻塞本地前端或 Agent 运行

#### Scenario: 引用失效
- **WHEN** 手机使用的历史游标或长内容引用因会话内容变化而失效
- **THEN** 返回可区分的失效结果，手机重新获取最新快照或条目，不拼接新旧两个版本的内容

### Requirement: 文字提交与持久去重

文字提交 SHALL 使用绑定电脑、主会话及原始内容的稳定业务请求标识，按现有持久输入语义受理；成功回执表示输入已受理，不表示回答完成。相同请求重复或网关重启后重试 MUST 不重复输入。App SHALL 可查询受理状态，未知结果不能冒充失败或成功。忙碌时 SHALL 与 Web 相同由电脑持久排队（缺省），或在用户显式选择时作为引导（steer）插入；回执 SHALL 标明是否排队。排队由电脑服务完成，客户端不得自行缓存或延后发送。

#### Scenario: 成功回执丢失
- **WHEN** 电脑已持久受理输入但手机断线未收到回执
- **THEN** 重新连接后查询或用同一请求标识和原内容重试可确认受理，不产生第二条用户输入或第二次相同任务

#### Scenario: 忙碌时提交
- **WHEN** 主会话正在运行时手机提交文字
- **THEN** 电脑持久受理并排队（或按用户选择引导当前运行），手机显示已受理及排队状态，与 TUI/Web 观察到同一条输入

#### Scenario: 受理失败
- **WHEN** 参数无效、会话已失效或电脑缺少模型凭据
- **THEN** 返回实际拒绝原因，手机保留草稿，不显示输入已发送或自动改为其他提交策略

### Requirement: 子 agent 连续查看与用量

移动 API SHALL 通过主会话提供稳定子 agent 列表、连续历史、各轮任务及当前运行状态，按主子归属校验详情、历史和停止。详情 SHALL 包含与主会话同类的可见内容、累计及可确认的本轮用量，沿用电脑的去重汇总。停止 MUST 绑定目标活动轮；详情不得提交子会话输入或直接派发任务。

#### Scenario: 接续和用量
- **WHEN** 主 agent 多轮使用同一个子 agent，手机同时查看主/子内容
- **THEN** 列表保持同一身份并展示轮数，连续历史可查看，主总用量不因手机观察而重复累计

#### Scenario: 旧轮停止
- **WHEN** 子 agent 已进入下一轮但手机使用上一轮的停止引用
- **THEN** 返回已结束或引用失效，不停止新一轮或其他任务

### Requirement: 跨端审批一致性

移动 API SHALL 汇总提供所属主会话下各子 agent 的未决 Bash 审批及完整命令、目录、显式超时、请求身份和决定版本，并支持允许本次与拒绝。决定 MUST 复用电脑的持久审批语义，校验当前请求和委派关系；多个前端竞争只能产生一个有效决定，重连不重新弹出已结算请求，不绕过审批执行命令。

#### Scenario: 手机与电脑竞争
- **WHEN** 手机允许本次时 Web/TUI 已经拒绝同一审批
- **THEN** 手机收到最终拒绝状态，不重复执行，不因手机旧界面覆盖电脑决定

#### Scenario: 请求结束或授权撤销
- **WHEN** 子任务已停止、审批已失效或设备被撤销后手机发送决定
- **THEN** 决定被拒绝或返回实际终态，不执行命令；其他有效前端仍可处理尚未结算的请求
