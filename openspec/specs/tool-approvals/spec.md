# tool-approvals Specification

## Purpose

为需要用户授权的工具调用提供逐次审批，明确展示待执行操作并保存用户决定，使多端观察、断线重连、进程恢复和任务取消时的授权边界一致，避免未经批准执行或自动重复执行有副作用的操作。

## Requirements

### Requirement: 逐次明确授权
系统 SHALL 在 explore 的每次 Bash 调用执行前请求用户审批，展示所属子任务、完整命令、工作目录和调用参数（含显式超时）。用户 SHALL 可选择仅允许本次或拒绝。授权 MUST 绑定具体调用及其操作内容，不能被模型、普通聊天消息或其他调用复用；未经允许不得启动命令。

#### Scenario: 允许与拒绝
- **WHEN** 用户允许或拒绝一个待审批命令
- **THEN** 允许时仅执行该调用，拒绝时不启动命令并把拒绝结果返回子 agent，由它选择其他方法或报告限制

#### Scenario: 操作改变
- **WHEN** 待执行命令、工作目录或参数与获批内容不一致
- **THEN** 旧授权不能放行改变后的操作，系统拒绝执行或创建新的明确审批

#### Scenario: 新调用和无客户端
- **WHEN** 子 agent 再次提交相同命令，或审批期间没有连接的前端
- **THEN** 新调用仍需单独批准，未获决定的请求保持等待而不自动放行

### Requirement: 持久审批与竞争处理
系统 SHALL 持久保存审批身份、操作内容、决定、关联子 agent 和当前委派轮次，提供 pending、allowed、denied、cancelled 状态。接续执行时 SHALL 将新请求关联当前轮而非首个历史委派；相同调用的恢复 SHALL 复用原请求；多端决定 SHALL 原子结算，只有第一次有效决定生效，重复或冲突提交返回已结算状态。审批状态 MUST 与命令运行状态分开表达，允许不代表执行成功。

#### Scenario: 双端同时操作
- **WHEN** Web 允许与 TUI 拒绝同一请求同时到达
- **THEN** 只有一个决定生效，两端最终展示相同结果，不重复执行

#### Scenario: 重连与等待期重启
- **WHEN** 前端断线或 gateway 在等待审批时重启
- **THEN** 重连后仍可处理同一未决请求；已持久保存的决定不会丢失或重复询问

#### Scenario: 接续轮的新命令
- **WHEN** 同一子 agent 在第二轮再次请求第一轮曾获批的相同 Bash 命令
- **THEN** 产生属于第二轮的新审批，原批准不复用；输入区只显示当前未决操作，结果附于该次命令

#### Scenario: 旧轮决定迟到
- **WHEN** 上一轮已停止或结算、下一轮已开始，客户端对旧请求提交决定
- **THEN** 仅返回旧请求最终状态或失效错误，不能授权、取消或更改下一轮的命令

### Requirement: 取消与执行恢复边界
停止子任务、停止主任务或归档所属主会话 SHALL 使未决审批失效，并取消相应等待；迟到决定 MUST NOT 启动已取消任务。进入执行阶段的 Bash 中断后 MUST NOT 自动重跑，必须报告可能已部分执行。取消不承诺回滚已发生的效果。

#### Scenario: 停止和批准竞争
- **WHEN** 用户停止任务时另一端正在批准命令
- **THEN** 按已提交的任务和审批状态处理，取消后不得启动新命令；已经启动的命令沿现有取消流程停止

#### Scenario: 执行期间重启
- **WHEN** 获批命令进入执行阶段后 gateway 重启
- **THEN** 返回明确中断结果，不自动重复执行；模型发起的后续新调用重新审批

### Requirement: 后台任务不绕过 explore 审批边界
explore 子 agent 的每次 Bash 调用审批边界 SHALL 保持不变，后台任务能力 MUST NOT 成为绕过它的途径：`job` 工具不提供给任何子 agent，审批请求只针对 explore 的 Bash 调用，不因后台任务产生新的审批类型。主会话 agent 的 `job start` 与其 `bash` 一致，不经逐次审批。

#### Scenario: explore 无法启动后台命令
- **WHEN** explore 子 agent 需要执行长期命令
- **THEN** 其工具集中没有 `job`，只能通过需审批的 Bash 调用，未经允许不启动命令

#### Scenario: 审批流程不受影响
- **WHEN** 主会话存在运行中 job，同时 explore 子 agent 提交 Bash 审批
- **THEN** 审批的展示、决定与结算行为与没有 job 时相同
