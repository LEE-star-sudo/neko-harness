# workspace-management Specification

## Purpose

管理 Harness 宿主上的工作区目录，使工作区能够独立于会话持久存在，并通过统一的目录浏览、添加和订阅能力，为多个前端提供一致的会话归属与工作上下文。

## Requirements

### Requirement: 独立工作区目录

系统 SHALL 持久保存工作区，以规范化的宿主真实绝对目录作为身份。工作区 MUST 独立于会话存在，重复添加同一真实目录 SHALL 返回已有工作区；子目录 SHALL 保持独立，不自动提升到 Git 根。

#### Scenario: 空工作区与重启

- **WHEN** 用户添加目录但未创建会话，随后重启网关
- **THEN** 工作区仍在目录中且没有因此产生空会话

#### Scenario: 最后一个会话归档

- **WHEN** 工作区最后一个会话被归档
- **THEN** 工作区仍存在，归档不删除宿主文件

#### Scenario: 重复路径与子目录

- **WHEN** 两个客户端同时添加同一目录或指向它的符号链接，随后添加其子目录
- **THEN** 同一真实目录只有一个工作区，子目录形成独立工作区

### Requirement: 宿主目录浏览与验证

系统 SHALL 提供 Harness 宿主目录浏览，返回当前真实路径、父目录和可进入的子目录，支持名称过滤、分页及显式显示隐藏目录。添加时 MUST 重新验证目录存在且可访问；浏览和添加 MUST NOT 上传内容、创建目录或修改宿主文件。

#### Scenario: 浏览与定位

- **WHEN** 用户逐层浏览、返回上级或输入完整目录路径
- **THEN** 系统展示该宿主目录的子目录及真实路径，不将普通文件作为可选工作区；根目录没有上级入口

#### Scenario: 隐藏目录和长列表

- **WHEN** 目录包含隐藏项及超过一页的子目录
- **THEN** 默认隐藏隐藏项，显式开启后可见；分页和过滤使用户能够访问所有匹配目录，不静默截断

#### Scenario: 无效目录

- **WHEN** 提交的路径不存在、不是目录、无访问权限或在浏览后被移除
- **THEN** 返回可理解的错误，不添加工作区，不改用默认目录

### Requirement: 已有会话接入与同步

系统 SHALL 将已有会话保存的工作区纳入独立工作区目录；新建和分叉会话的工作区 SHALL 自动登记。工作区目录变化 MUST 推送给已连接前端，且不得改变既有会话的工具目录。工作区仍是工作上下文，不构成权限沙箱。

#### Scenario: 升级现有存储

- **WHEN** 重开包含规范化工作区路径的已有会话存储
- **THEN** 幂等登记其工作区，保留会话标识、历史、归档状态和目录；重复启动不产生重复工作区

#### Scenario: 多客户端添加

- **WHEN** Web 添加工作区或 TUI 在新目录创建会话
- **THEN** 所有工作区目录订阅者收到对应工作区，Web 可进入该工作区查看其非归档会话

#### Scenario: 已保存目录失效

- **WHEN** 已登记工作区的宿主目录被移动或删除
- **THEN** 保留该工作区及历史归属，可继续查看历史；依赖目录的操作明确报错，不静默重新绑定路径
