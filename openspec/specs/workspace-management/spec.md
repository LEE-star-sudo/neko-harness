# workspace-management Specification

## Purpose

管理 Harness 宿主上的工作区目录，使工作区能够独立于会话持久存在，并通过统一的目录浏览、添加和订阅能力，为多个前端提供一致的会话归属与工作上下文。

## Requirements

### Requirement: 独立工作区目录

系统 SHALL 持久保存工作区，以规范化的宿主真实绝对目录作为身份。工作区 MUST 独立于会话存在，重复添加同一真实目录 SHALL 返回已有工作区；子目录 SHALL 保持独立，不自动提升到 Git 根。

#### Scenario: 空工作区与重启

- **WHEN** 用户添加目录但未创建会话，随后重启网关
- **THEN** 工作区仍在目录中且没有因此产生空会话

#### Scenario: 最后一个会话归档

- **WHEN** 工作区最后一个会话被归档
- **THEN** 工作区仍存在，归档不删除宿主文件

#### Scenario: 重复路径与子目录

- **WHEN** 两个客户端同时添加同一目录或指向它的符号链接，随后添加其子目录
- **THEN** 同一真实目录只有一个工作区，子目录形成独立工作区

### Requirement: 宿主目录浏览与验证

系统 SHALL 提供 Harness 宿主目录浏览，返回当前真实路径、父目录和可进入的子目录，支持名称过滤、分页及显式显示隐藏目录。添加时 MUST 重新验证目录存在且可访问；浏览和添加 MUST NOT 上传内容、创建目录或修改宿主文件。

#### Scenario: 浏览与定位

- **WHEN** 用户逐层浏览、返回上级或输入完整目录路径
- **THEN** 系统展示该宿主目录的子目录及真实路径，不将普通文件作为可选工作区；根目录没有上级入口

#### Scenario: 隐藏目录和长列表

- **WHEN** 目录包含隐藏项及超过一页的子目录
- **THEN** 默认隐藏隐藏项，显式开启后可见；分页和过滤使用户能够访问所有匹配目录，不静默截断

#### Scenario: 无效目录

- **WHEN** 提交的路径不存在、不是目录、无访问权限或在浏览后被移除
- **THEN** 返回可理解的错误，不添加工作区，不改用默认目录

### Requirement: 已有会话接入与同步

系统 SHALL 将已有会话保存的工作区纳入独立工作区目录；新建和分叉会话的工作区 SHALL 自动登记。工作区目录变化 MUST 推送给已连接前端，且不得改变既有会话的工具目录。工作区仍是工作上下文，不构成权限沙箱。

#### Scenario: 升级现有存储

- **WHEN** 重开包含规范化工作区路径的已有会话存储
- **THEN** 幂等登记其工作区，保留会话标识、历史、归档状态和目录；重复启动不产生重复工作区

#### Scenario: 多客户端添加

- **WHEN** Web 添加工作区或 TUI 在新目录创建会话
- **THEN** 所有工作区目录订阅者收到对应工作区，Web 可进入该工作区查看其非归档会话

#### Scenario: 已保存目录失效

- **WHEN** 已登记工作区的宿主目录被移动或删除
- **THEN** 保留该工作区及历史归属，可继续查看历史；依赖目录的操作明确报错，不静默重新绑定路径

### Requirement: 工作区文件候选

系统 SHALL 为 @ 引用提供工作区文件与目录候选，支持空查询、名称模糊搜索和相对目录定位，安装后无需额外安装文件发现工具。候选 MUST 使用工作区相对路径，不提升到 Git 根；包含合法隐藏项、排除 .git，遵守工作树的 Git 忽略规则，不读取 fd 专用或 .ignore 文件。真实目标 MUST 位于当前工作区；该限制不改变工具访问权限。枚举不完整与候选过多 SHALL 分开标识，前者不得伪装为无匹配。

#### Scenario: 定位与搜索

- **WHEN** 用户在工作区 B 输入 @、@runtime 或 @packages/core/
- **THEN** 分别展示 B 的直接子项、名称匹配结果或指定目录内候选，目录可辨识，同名文件可通过父路径区分

#### Scenario: 忽略与越界

- **WHEN** 工作区包含 Git 忽略项、隐藏项、.git、外部符号链接，或用户输入越出根目录的路径
- **THEN** 忽略项、.git 和真实目标在工作区外的条目不成为候选；合法隐藏项可见，越界查询明确拒绝

#### Scenario: 大目录与失效目录

- **WHEN** 候选超过返回限制、枚举达到资源上限、查询超时或工作区已删除
- **THEN** 查询有界结束，分别反馈候选过多、不完整、超时或目录失效，可缩小范围或重试，不静默切换目录

#### Scenario: 无外部工具安装

- **WHEN** 支持平台正常安装 neko 后，宿主 PATH 中没有 fd 或 fdfind
- **THEN** 两端仍可查询文件候选，不要求安装工具或建立命令别名

#### Scenario: 不完整索引中的查询

- **WHEN** 工作区枚举被截断，当前索引没有匹配，用户随后指定包含目标的子目录
- **THEN** 初次查询明确提示结果不完整；后续直接查询该子目录，不因根索引截断永久漏掉目标

#### Scenario: 忽略规则来源

- **WHEN** Git 工作树配置父级/子级 .gitignore、info/exclude 或全局 Git excludes，另有 .ignore/.fdignore；或非 Git 目录存在 .gitignore
- **THEN** 只沿用原生 Git 忽略语义；.ignore/.fdignore 不改变候选，非工作树的 .gitignore 不作为忽略规则

### Requirement: 路径引用与附件语义

普通文件及目录选择 SHALL 插入可编辑的 @ 相对路径，带空格的路径 SHALL 正确引用。搜索及选择 MUST NOT 加载正文、递归展开目录或自动发送消息；引用作为消息文字由模型按需使用现有工具读取。图片 SHALL 沿用图片附件能力和模型校验，失败时保留草稿并明确反馈。

#### Scenario: 文件和目录引用

- **WHEN** 用户选择带空格的文件或目录并发送问题
- **THEN** 引用路径准确保留，目录可作为引用发送，消息不包含自动附加的文件全文或目录树

#### Scenario: 图片与失效文件

- **WHEN** 用户选择图片，或选择后文件被删除
- **THEN** 图片处理遵循既有附件限制且不自动发送；普通路径引用仍为文字，实际读取失败由工具反馈，不伪称已附加内容

### Requirement: 文件候选缓存与刷新

文件候选缓存 SHALL 有界、按工作区及目录隔离，由多个客户端共享。文件创建、删除、重命名和忽略变化 SHALL 使后续查询刷新；事件未捕获时，缓存最多有效 30 秒，到期后的查询 MUST 重建。移除工作区、空闲淘汰及关闭 SHALL 回收观察和扫描资源。取消或失效查询 MUST 不覆盖新请求，单客户端取消不得破坏其他客户端正在等待的共同查询。

#### Scenario: 文件与忽略变化

- **WHEN** 已查询的目录新增、删除或重命名文件，或修改忽略规则后再次查询
- **THEN** 已观察变化使相关缓存失效；未观察到的变化在 30 秒有效期结束后的查询刷新，不永久复用旧候选

#### Scenario: 多客户端与取消

- **WHEN** TUI/Web 同时查询同一目录，其中一端取消、切换会话或关闭候选
- **THEN** 另一端的查询仍可完成，旧响应不覆盖新工作区或恢复已关闭面板

#### Scenario: 长期运行与关闭

- **WHEN** 用户连续查询多个大工作区，随后移除工作区、停止查询或关闭网关
- **THEN** 缓存按上限淘汰，空闲与失效资源回收，关闭后没有遗留观察、扫描或辅助进程

#### Scenario: 观察或辅助进程失效

- **WHEN** 文件观察失效、报告漏事件，或文件发现辅助进程退出
- **THEN** 相关缓存不能继续充当有效新快照；观察失败仍可过期刷新，进程故障明确反馈且后续查询可重试，不终止普通聊天
